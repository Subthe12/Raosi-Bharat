## Images
New recipe cards do not embed scraped commercial photographs. They request a matching image from Wikimedia Commons at runtime using the dish name and regional context, then cache the image URL locally. The exact Commons file and license can vary; review individual image licenses/attribution requirements before Microsoft Store submission.
